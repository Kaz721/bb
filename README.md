# HTTP Ping Monitor

This project safely pings your server over HTTP and logs status/latency.

## Run

```bash
python3 http_ping.py
```

Useful options:

```bash
python3 http_ping.py --url http://162.243.172.250 --interval 5 --timeout 3 --count 10
```

## Download command

```bash
git clone https://github.com/Kaz721/bb.git
```

Then:

```bash
cd bb
python3 http_ping.py
```
